# CartShare - Collaborative Shopping Ecosystem
## Features
- Create / Join Room with unique code
- Add / Remove items from shared cart
- Real-time Activity Log with who added what
- LocalStorage persistence
- Multi-tab sync using storage event
- Free Delivery Progress ($75 threshold)
- Fair Split + Printable Receipt (CSS print media)
## How to Run
Open index.html in browser. Open in 2 tabs with different names to test collaboration.
